# Designing-pedestrian-zones-multifunctional-spaces-in-the-urban-environment
В этом репозитории размещены материалы по научно-исследовательским работам на тему \
**"Формирование и модификация пешеходных зон – мультифункционального пространства городской среды для территорий существующей застройки."**

## НИР 1 - анализ предметной области и обоснование актуальности разрабатываемого метода

- Формулировка сущности системы многофункциональных пешеходных зон
- Анализ и описание методов оценки характеристик пешеходных и общественных пространств
- Анализ состава и доступности исходных данных
- Планирование результатов дальнейшей работы
### Вложенные файлы по НИР 1
- Текстовый отчёт в формате .docx
- Презентация расширенная в формате .pdf


## НИР 2

- Сформулированы принципы интерпретации данных и рекомендации.
- Продемонстрировано применение первой версии алгоритма.
- Подготовлены и проанализированы исходные данные.
